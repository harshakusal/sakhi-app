How to install

ఎలా ఇన్‌స్టాల్ చేయాలి

  1. Tap Download APK above.
  2. Open the downloaded Sakhi-v0.7.1.apk.
  3. If asked, choose Settings → allow install from this source.
  4. Tap Install, then open Sakhi.
  1. పైన APK డౌన్‌లోడ్ నొక్కండి.
